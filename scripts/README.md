# scripts

## 📌 Visão Geral
Módulo integrante da arquitetura do repositório GAROS no caminho `garos-control-api/scripts`.

## ⚙️ O que esta pasta faz
- Automatizar fluxos de compilação, testes automatizados e orquestração de ambiente.

## 📂 Conteúdo e Arquivos Detalhados
- `generate-jwt.sh`: **[Script Shell de Automação]** — Script automatizado de sistema que orquestra as ferramentas `cargo`.
- `install-nixos.sh`: **[Script Shell de Automação]** — Script automatizado de sistema que orquestra as ferramentas `nix`.
- `setup-dev.sh`: **[Script Shell de Automação]** — Script automatizado de sistema que orquestra as ferramentas `cargo, curl`.
- `smoke-test.sh`: **[Script Shell de Automação]** — Script automatizado de sistema que orquestra as ferramentas `jq, curl, systemctl`.
